# AGENTS Guide

This is a starter template for AI coding assistant guidance.

## How to use this file

- Replace placeholders with your project rules.
- Keep one canonical file and have tool-specific files point to it.
- Keep instructions short, concrete, and testable.

## Suggested sections

- Scope and precedence
- Coding conventions
- Required checks
- Security and privacy limits
- Change management rules

## Example checks

- Install: npm install
- Build: npm run build
- Test: npm test
- Lint: npm run lint
